# freeCodeCamp Scientific Computing with Python

This repository contains my solutions to the five projects required for freeCodeCamp's _Scientific Computing with Python_ certification.

## Projects

### 1. Arithmetic Formatter
Formats arithmetic problems vertically and side by side, with optional answer calculations.

### 2. Time Calculator
Performs time arithmetic by adding a duration to a starting time and determining the resulting time and day.

### 3. Budget App
Uses object-oriented programming to manage budget categories, deposits, withdrawals, transfers, and spending charts.

### 4. Polygon Area Calculator
Uses classes and inheritance to calculate geometric properties of rectangles and squares.

### 5. Probability Calculator
Uses random sampling and repeated experiments to estimate the probability of drawing specified combinations of colored balls.

## Skills Practiced

- Python functions and control flow
- Lists, dictionaries, and string manipulation
- Object-oriented programming and inheritance
- Working with random sampling and probability
- Writing reusable code and testing program behavior

These projects represent my progress in learning Python through hands-on problem solving. My goal is to continue developing practical programming skills and building projects that solve real-world problems.
